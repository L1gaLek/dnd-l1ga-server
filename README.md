# dnd-l1ga-server

## Campaign source of truth

Use `Кампания_Седьмой_Рассвет_Глава_1,2,3.docx` as the current campaign reference when continuing work on **«Седьмой Рассвет»**.

The document combines chapters 1, 2, and 3 and should be treated as the authoritative source for:

- the Greyhollow setting and the seven-day loop;
- the Last Hearth tavern as the party's safe location;
- the Dawn Eater, the seven seals, and the ritual history;
- campaign pacing, level milestones, clue structure, rewards, and night attacks;
- all chapter 3 additions now included with the first two chapters.

When adding future campaign content, keep new notes, server data, and player-facing text consistent with that document unless the campaign file is replaced by a newer combined version.
Additional continuation material is kept in `Кампания_Седьмой_Рассвет_Продолжение.md`, which expands chapters 4–14 with NPCs, location clue handling, mistakes and consequences, daily clues, night attacks, mini-boss abilities, rewards, and finale outcomes.
